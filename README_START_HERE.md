# PowerPath submission bundle

This ZIP contains the application in `team_app/`, the official supplied data and checker in `data/` and `starter/`, four provided saved result sets in `outputs/`, and the fast regression tests in `team_app/tests/`.

## Quick start
```bash
python -m pip install -r requirements.txt
streamlit run team_app/app.py
```

## Headless run and validation
```bash
python team_app/run.py recommend --out outputs/new_recommendation
python starter/check_submission.py outputs/new_recommendation/portfolio.json outputs/new_recommendation/dispatch.csv
python -m unittest discover -s team_app/tests -v
```
The optimization may take time, depending on machine and candidate dates. Saved outputs are from the uploaded version and have not been regenerated by this patch.

## Changes
- Fixed contradictory opening-window handling.
- Added PermitIQ conservative screening tab and downloadable human-review checklist.
- Reframed Texas large-load and air authorization statements as unverified diligence, not compliance certifications.
- Clarified demo preset, valuation vs checker totals, and sampled-model optimality caveats.
- Bundled official packet dependencies for clean extraction and added regression smoke tests.

## Scope
The original numerical solver is substantially unchanged. Optional permit/procurement delays are scenario sensitivities, not verified actual availability dates. No live legal monitoring, marketplace inventory, regulatory approvals, or guaranteed project completion date is provided.
