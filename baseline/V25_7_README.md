# PowerPath v25.7 quick start

Open **PowerPath.html**, go to **Project Intelligence → Underwrite**.

- Set individual building MW, construction schedule, connection date, lease period and rent method.
- Underwrite construction and refinance debt, scheduled principal, restrictions, DSRA and distributions.
- New in v25.7: use **Sponsor commitment ($M)** to set the maximum total sponsor equity including initial invested cash. Leave blank only to perform a sensitivity with unverified/unlimited funding. A recorded amount is not independently confirmed.
- Enter **Cash tax proxy (%)**, **Maintenance capex ($M/IT MW/year)**, and **Working capital days** to calculate annualized forward CFADS, DSCR and refinance capacity. These are *simplifying inputs*, not a contractual cash-waterfall definition.
- Choose **Underwrite project**, inspect funding defaults and monthly ledger, export schedule CSV.
- Source fixtures, 19 JavaScript test scripts, independent Python monthly financial model and detailed audit files are in the source bundle.

**Important:** Mathematical reconciliation is not a substitute for financial audit. v25.7 remains NOT independently lender-certified.
