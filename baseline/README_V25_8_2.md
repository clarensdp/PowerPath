# PowerPath v25.8.2 — Quick Start
Open `PowerPath.html` in a modern browser for the standalone local prototype. Under Project Intelligence → Underwrite, use the new fields:
- Refinance tenor: Fixed / Within remaining lease term
- At lease expiry: Vacate / Probability-weighted renewal
- Exit value: Fixed / Leased-vs-vacant capacity
These are **synthetic scenarios**, not contractual facts. Review the model assurance warning at the top of results.

For source and testing: see `V25_8_2_AUDIT_ADOPTION.md`.
Do not upload confidential documents to the browser/local vault without production security review.
